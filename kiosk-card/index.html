LexiPic

Heritage Archive · Kiosk

Enter the full URL of any kiosk page — for example, a LexiPic Kiosk site's fullscreen URL or shortcode page. The PWA displays that page directly, fullscreen, with auto-reload to recover from connection drops. An internet connection is required.

Plug in your USB drive and click the button below to select the lexipic-kiosk-data folder from it. The folder must contain a settings.json file that lists which word sets to show.

settings.json format 
{
  "layers": [
    { "slug": "domestic-animals", "name": "Domestic Animals",
      "enabled": true, "group": "Nature" },
    { "slug": "numbers", "name": "Numbers 1–10",
      "enabled": true, "group": "Learning" },
    { "slug": "colours", "name": "Colours",
      "enabled": false, "group": "Learning" }
  ],
  "kiosk": {
    "idle_time_seconds": 90,
    "autoplay_audio": false
  }
}

Each slug maps to a {slug}.json file in the same directory. Sets with "enabled": false are hidden. name overrides the set's own name. group labels are shown as section headers on the tile grid. Images and audio can be data: URIs embedded in the set JSON, or plain filenames relative to the data folder (e.g. "image": "cat.jpg").

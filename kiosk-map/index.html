MediaMap

Interactive Map · Kiosk

Enter the full URL of any kiosk page — for example, a MediaMap Kiosk site's fullscreen URL or shortcode page. The PWA displays that page directly, fullscreen, with auto-reload to recover from connection drops. An internet connection is required.

Plug in your USB drive and click the button below to select the mediamap-kiosk-data folder from it. The folder must contain a settings.json file that lists which layers to show. The map's basemap tiles still load from the internet — only the layer data (points/shapes) works fully offline.

settings.json format 
{
  "layers": [
    { "file": "heritage-sites.json", "name": "Heritage Sites",
      "enabled": true },
    { "file": "river-course.geojson", "name": "River Course",
      "enabled": true,
      "shapeStyle": { "fillColor": "#4f46e5", "lineColor": "#4f46e5" } }
  ],
  "kiosk": {
    "idle_time_seconds": 90,
    "lock_bounds_to_data": false
  }
}

Each file is a JSON or GeoJSON file in the same directory, in the same format the MediaMap Kiosk plugin's importer accepts: a plain array of {lat, lng, place_name, media_type, media_url, description} points, {"data": [...]}, or a GeoJSON FeatureCollection/Feature/geometry. Point/MultiPoint geometries become map pins; LineString/Polygon geometries become styled shapes. Layers with "enabled": false are skipped. shapeStyle is optional and overrides the default shape colors/label for that layer. A point's media_url can be a remote link, or a plain filename relative to the data folder for local images/audio/video.
